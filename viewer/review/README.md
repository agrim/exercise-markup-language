# EML rendering checks

These images came from the local WebGL viewer using the shipped 222,579-triangle atlas, compiled local joint rotations, and registry equipment components. The browser loaded each of the 108 catalog documents and all three custom examples. For each document it scrubbed to a sample and captured the canvas. The catalog sheets show the phase endpoint with the greatest total displacement of the head, pelvis, hands and feet from setup. Static holds are shown halfway through the interval.

The browser check also loaded a recipe with an ID absent from the catalog, changed a declared parameter and reapplied it to the current phase, toggled playback, switched camera, and submitted malformed JSON while retaining the valid preview. The sheets show a single pose per document. Assess the full rep in the [interactive viewer](../README.md) and use the numerical checks for constraints and repetition boundaries.
